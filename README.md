# CIVICFIX AI

AI-powered civic issue reporting and prioritization platform.

## Features

- Citizen civic issue reporting
- AI-based issue classification
- Priority scoring
- Complaint tracking
- Authority dashboard
- Status management
- Image upload support

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
